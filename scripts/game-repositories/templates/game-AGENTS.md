# 独立游戏仓库开发指引

- 使用中文沟通。本仓库只维护当前游戏及其扩展玩法，不增加其他独立游戏，也不放入平台账号、房间、数据库、通用运行时或生产配置。
- 后续游戏继续在 https://github.com/PlayBoardgameTogether 组织下使用每游戏独立仓库；通用平台能力进入 PlayBoardgameTogether/PlayBoardgameTogether。
- 开始前检查 Git 分支、状态、远程并 fetch origin main。保留用户改动；从 main 开发时创建 codex/ 功能分支。只提交本轮文件，推送并创建 PR，不改写共享历史。
- SOURCE.json 记录初始来源与兼容性快照；不将固定 SDK/解析器快照当成平台源码的另一个维护来源。修改契约时协调平台 PR 和兼容版本，分别交付。
- 规则只使用注入的确定性 RNG；完整 State 留在服务端。客户端和 AI 只读本人 View，事件经过投影。不得绕过平台身份、事务、requestId、revision 和控制权检查。
- 已发布精确版本不可覆盖。规则、桌面或资源变化提升游戏自身版本；不因为游戏更新递增平台版本。README 中的命令为本仓库验证入口，提交前实际执行适用检查并如实记录结果。
- 在线包发布以规范的三文件安装 ZIP 为准，普通 GitHub 源码 ZIP、可信内置游戏 tgz 均不能作为在线安装包。发布不会自动上架或部署平台，管理员仍需检查审核。
- 不提交 .env、凭据、会话、数据库、node_modules 或 dist。第三方本机资源不随仓库发布。平台中的锁定集成副本不得直接维护，先在本仓库修改、验证、合并再更新平台锁定版本。
