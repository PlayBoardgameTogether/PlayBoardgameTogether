## 玩法与操作

106 张牌，每人 14 张，随机先手。同数不同色的 3–4 张，或同色连续的至少 3 张构成合法组；1 不接 13。首次只能用自己的牌，合计至少 30 分，百搭按代表数字计分；该回合不能改动桌面。从之后的回合开始可追加、拆分、合并和重组。提交时全部旧桌面牌必须保留在合法组中，且至少使用一张手牌。百搭可替换并在本回合重用，不能拿回手牌。

点击牌多选，按选择顺序放入新组或用目标组两侧箭头追加；桌面选牌后移至新组即可拆分。初始出牌之前旧公共牌不能选择。新增牌可以放回牌架；旧公共牌不能收回。按颜色/数字排序只调整自己的排列，不提交动作。无效组以淡红色下划线及具体原因提示；服务端继续独立校验。

新手牌草稿只保存在当前桌面，已有公共牌的临时排列通过 `arrange_public` 同步给其他玩家，可撤销或还原。刷新恢复已保存的公共排列，清除本地新手牌草稿。同步不改变已确认组合、回合、手牌或计分，不消耗 RNG；确认仍校验完整桌面并至少使用一张手牌。确认或摸牌结束回合时清除临时排列。有草稿时摸牌按钮禁用，先还原桌面。摸一张立即结束回合，不可立即出新摸的牌；牌堆空时跳过，全员连续跳过结束。先清空牌架获胜，其他玩家扣剩余牌总分，百搭扣 30，赢家得到其罚分总和；耗尽结局按最低余牌点数，并列者平分其他人与最低分的差额。本版没有回合计时、超时罚摸和多局累计赛。

公共排列复用正式动作的身份、控制权、revision、回执、事务与实时投影，每次同步推进 match revision、持久化并可回放，但不推进游戏回合 `move`。仅当前已破冰玩家能整理，必须恰好包含所有已有公共牌，不接受手牌、重复、遗漏或外来牌；服务端允许临时组合不合法。同步期间沿用动作忙碌保护，不新建通信通道。内容版本为 1.1.0，不兼容旧版 State；已安装的旧包及旧局不被覆盖。

## 维护与边界

`shared.txt` 仅含公开牌号和合法组合语义，打包时同时写入服务端规则和浏览器；它不含 State 或他人手牌。`server.txt` 拥有洗牌、隐藏牌堆/手牌、出牌、回合、计分和守恒存档校验。`client.html` 只读取本人 View，草稿通过原 sandbox 消息桥交给 matches。安装后版本不可覆盖，更新规则/桌面时须提升 manifest 版本并修改打包输出名，旧局继续使用精确旧版本。

基础 AI 使用本人手牌成组、已有组两端追加的有限搜索，不能穷尽复杂桌面拆分或给出最佳解；模型 AI 也仅使用这些候选。本包提供原创美术，不包含官方素材、平台音效、可切换图包或交互教程。基础规则参考 [官方说明](https://rummikub.com/wp-content/uploads/2019/12/2600-English.pdf)，本地明确的无计时、随机先手、连续跳过及并列分摊规则以上述说明为准。
