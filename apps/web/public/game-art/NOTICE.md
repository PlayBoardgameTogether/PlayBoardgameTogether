# 游戏目录插画

此目录的 SVG 与 WebP 随项目源码分发，供大厅及游戏详情展示。

`catalog-20261107/` 中的游戏头像取自独立游戏仓库中已合并的方形原画 `design/pixel-catalog-art/<游戏键>/icon-source.png`，宽幅场景取自同一提交的 `design/background-drafts/<游戏键>/background-source.png`。精确提交见项目文档 `docs/game-avatar-art-2026-11-01.md` 的合并记录。平台展示副本分别以 512 像素和 960 像素宽度输出为 WebP。

计数房间演示的两张 WebP 使用内置 ImageGen 生成宽画面，再为头像输出方形构图。生成提示词如下。

> Use case: game-art. Create a single wide 3:2 pixel-art illustration for the PlayBoard tabletop site’s counting room demonstration, used in a right-hand game detail panel and as a wide thumbnail. Depict a tactile ivory D6 die with five black pips on top and three small amber wooden counting cubes on a warm walnut game table, a subtle olive felt patch, late-afternoon window light. Main cluster large, centered slightly right, with a little breathing room at every edge so 16:9 and square crops retain the die. Premium hand-pixeled retro adventure game prop illustration, visible crisp deliberate pixel clusters, restrained pine green, walnut, amber and bone colors, material detail and gentle clean shadows. Edge-to-edge artwork. No people, no letters, no labels, no words, no border, no logos, no watermarks, no gradients or blur.
