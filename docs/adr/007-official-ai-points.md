# ADR-007：官方 AI 沿用模型控制器，以成功行动结算点数

日期：2026-10-16。状态：Accepted（本轮用户已授权开发平台官方 AI 与点数）。

官方 AI 需要平台承担模型调用成本、用户明确授权消费，并避免余额并发超支及动作失败却扣费。现有个人模型配置、AI scheduler、matches 动作事务与隐私边界已经具备。

第一版将管理员来源模型发布为价格固定的官方档位，为玩家创建无凭证的本人官方配置。房间/本人控制仍引用 model profile，不增加第四种控制器或平行动作通道。每席位单局预算由用户显式选择，付款身份沿用固定参与者/model_owner_account_id，不能据此读取 bot View。

采用固定点数/成功行动。调用前以钱包行锁预留，调用在事务外，动作和扣点在原 match 事务原子提交。失败、过期、取消与兜底不收费，供应商成本独立记录，不把 token 或超时当作实际账单。task 一次调用、decision group 有界尝试及持久提案限制重试损耗；后台可发放点数并查看用量，不接支付。

这降低了首版价格理解与用量缺失时的结算复杂度，但平台承担失败调用及长上下文成本。后续按实测引入成本账单和按用量档位时，必须使用独立价格版本、明确授权及同等事务/恢复保护，不能追溯改变已结算账单。

具体接口与限制见 [官方 AI](../official-ai.md)。
