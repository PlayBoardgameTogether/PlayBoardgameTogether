# ADR-008：官方 AI 按实际 token 用量和管理员加价结算

日期：2026-10-18。状态：Accepted（用户要求按 token 算价格并由管理员调控加收）。

在 ADR-007 官方档位上新增可选 tokenPricing，记录输入/输出每百万 token 基础点价及加价百分比。继续使用 AI 点数，供应商成本换算由管理员填写，不新增支付或汇率服务。后台默认发布 token 档位，旧固定档位及发布契约继续兼容；调价发布新档位，玩家显式启用，不改变进行中授权价格。

沿用 task → wallet 锁、一次官方调用、身份化 View 与正式动作事务。调用前预留单次上限、可用余额、剩余单局预算中的最小值；BigInt 合计加价后向上取整。ready 冻结价格/用量/扣点并释放多余预留，动作与扣点原子提交。缺失用量、超预留及失败兜底免费；零费用行动释放预留而不插入零额账本。

上限限制玩家费用，平台承担失败或超预留的供应商成本。缓存/推理细分按 input/output 总量统一方向点价处理，管理员需独立核对供应商账单。033 不改写历史费用或旧迁移。pointsPerAction 对 token 档位为单次上限，通过 tokenPricing 区分，保持旧契约兼容。

公式与限制见 [官方 AI](../official-ai.md)。本记录扩展 ADR-007 计价方式，保留其身份、事务、预算、恢复与失败免费约束。
