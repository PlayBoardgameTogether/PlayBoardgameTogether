# 全界面体验评估与优化（2026-10-17）

本轮按用户授权评估当前界面并实施改善，平台版本从 0.8.2 升至 0.9.0。最高变更级别为兼容的交互增强：聊天阅读位置与回到最新消息、模型配置入口、移动棋桌与后台导航；同时修复错误反馈、回放恢复和诊断等待问题。

## 评估方法与覆盖

使用当前实例的 Chromium，先保存并查看本轮截图，再决定修改；原有截图未作为本轮审查证据。桌面为 1440×900，手机为 390×844 CSS 像素；自动化补查 320/700px 表单、1280px 模型设置及亮暗主题。截图、可访问 DOM、页面标题、溢出与控件尺寸清单保存在工作区 `.data/full-ui-audit/`，不提交测试会话或生成图片。完整带图报告为同目录 `report.md`。

共检查 41 类页面状态的桌面/手机版本，包括同一路由的访客与登录状态；另以真实测试账户创建房间，检查五种已安装游戏的等待房间、对局桌面和本人回放，并检查有消息的公聊、私聊及故障状态。操作按原账户、房间、CSRF、服务端规则与本人视图进行。未调用付费模型，未执行服务更新或合并发布分支。

## 逐项修复

### 1. 主题颜色的用途分离

原浅色主题直接把金色按钮填充当作正文链接色。当前截图中，文档、返回入口、注册与好友 ID 的部分文字明显偏淡。新增 `--link`，浅色为深琥珀色，深色仍用亮金；按钮继续使用原填充色。文档当前链接、下载入口与社交文字消费可读链接色。文字链接的自动化对比度检查要求至少 4.5:1。

同时把浅色错误、成功和警示文字改为较深语义色，错误背景与文字由同一套 Token 配对；行动提示不再使用不适配浅色底的淡蓝文字。没有用全站 `!important` 覆盖颜色。

### 2. 棋桌外壳不再污染浅色游戏背景

原 `.desktop-shell--game` 只把 `--bg` 改成深色，却继承浅色主题的深色正文，导致 Grid Garden 状态与花园标题几乎不可见。移除这种不完整的外壳覆盖；璀璨宝石与花砖仍拥有完整的独立沉浸配色。Grid Garden 的状态、能量、确认区与提示恢复一致的对比度。

### 3. 手机表单与触控

手机文本输入、选择框和多行输入使用至少 16px 字号，减少 iOS 聚焦输入时自动放大的风险；密码显示、聊天、模型表单和回放行动按钮保持至少 44px 可用高度。没有把花园网格等棋盘单元批量放大。

### 4. 注册页密度与字段恢复

将帮助文字与对应输入成组，去掉把帮助文字当作独立表单项产生的大间距，缩短重复说明；登录/注册卡使用现有轻阴影。前端校验失败、两次密码不一致和 ID 已占用时，聚焦对应字段，并提供 `aria-invalid` 与错误描述关联；编辑后清除旧字段错误，保留已填内容。服务端密码和身份校验不变。

### 5. 手机后台导航与账户子页

九个后台入口在手机上不再占据多行；导航自身横向滚动，页面不横向溢出。当前栏目在重新加载或切页后自动滚入可见区域，所有入口仍可键盘访问。玩家币与徽章管理属于账户管理，导航保持该栏目选中。返回大厅使用真实按钮链接外观。

### 6. 模型配置减负

去掉与列表重复的顶部数量卡、加密实现标签及重复服务商推荐；服务商快速配置改为可选折叠区，主要字段直接可见。没有配置时提供无需外部密钥的模拟入口，选择后聚焦名称，仍需主动保存。保留编辑、测试、复制、撤销、删除确认、高级参数和原 API；保存不会调用模型。无法保存密钥时解释用户可做什么，不把服务器环境变量名当作操作指南。

模型状态筛选改为按钮组与 `aria-pressed`，避免用不完整的 tablist 语义误导键盘及辅助技术。搜索输入为图标和清除按钮保留独立空间，清除按钮提供 44px 点击区域，避免主题覆盖后与文字重叠。

### 7. 好友查找与身份确认

好友列表无匹配结果时可直接清除筛选；搜索 ID 不自动大写或拼写修正。发送申请时携带搜索结果的 `expectedAccountId`，让服务端继续核验当前 ID 对应的身份，防止搜索与点击之间 ID 归属变化导致误加。

### 8. 聊天的读取错误与发送错误分开

修复前的真实故障截图可复现：消息发送响应丢失后，页面提示结果未知；约 5 秒后的正常轮询会清除该错误，但输入仍只读、按钮仍要求重试。现在轮询只处理读取错误，不会清除发送问题。待重试正文、请求 ID 和输入锁继续保留，重试不能重复产生消息。首次读取有加载提示，不提前显示“还没有消息”。

### 9. 聊天阅读位置与继续输入

加载更早消息前记录当前可见消息的实际位置，插入后恢复同一阅读位置，避免只根据整数滚动高度计算产生偏移。阅读旧消息时，新消息不把玩家拉到底部；可通过“回到最新消息”或“有新消息，回到最新”继续。本人发送成功后显示最新消息并聚焦输入；历史消息区域可键盘聚焦，跳到最新后焦点落在记录中。阅读旧私聊期间不推进新消息的已读位置，回到最新后才标记。保留 IME Enter 防误发、Shift+Enter 换行和消息去重。

### 10. 回放失败保持上下文

原实现读取任一步失败就清空 frame，整张棋桌消失、标题退回“回放”，重试从默认开头开始。现在暂时失败保留最后成功局面并停止自动播放，重试相同目标步骤和原动画意图；主动跳转仍使用原代次淘汰迟到响应。会话失效、禁止访问或对局不可访问仍清除私密视图。只读回放继续阻止正式动作。

### 11. 手机回放控件安全区

回放控制条的 sticky 底边消费平台底部安全距离，避免速度选择与行动按钮被底部主导航遮挡。保留进度、首尾、上下步和播放，不强迫玩家通过隐藏入口寻找控件。

### 12. 继续游戏分页防重复

加载更多参与房间使用同步锁和禁用状态，快速点击或同帧重复事件只产生一个请求；合并页面按房间 ID 去重。读取失败保留现有房间，清晰显示错误并允许原页面重试。

### 13. 系统状态可独立判断

API、数据库、WebSocket 同时检查并分别反馈；一个挂起的 HTTP 请求不会遮住其他结果。HTTP 包括正文读取最多等待 8 秒，WS 沿用 5 秒期限；检查中防重复，离页取消，不由迟到结果更新新页面。网络故障提示使用中文。

### 14. Color Match 手机信息密度

公共牌、剩余牌数与回合提示并排组织，玩家计数使用紧凑双列，手机隐藏与数字计数重复的装饰牌背，使手牌更早出现。目标选择按钮仍可见并保持 44px，继续遵循先选择、再确认的玩法；没有调换 DOM 阅读顺序或改变出牌规则。

### 15. 首次与不可用存储时跟随系统

修正主题读取及首屏脚本默认强制亮色与既有“跟随系统”约定不一致的问题。首次进入、无有效偏好、存储不可用时使用系统亮暗偏好；用户已选择的亮/暗主题继续优先。首屏与运行时使用相同规则，减少夜间先亮后暗的闪烁。

## 范围限制

这是一轮当前已安装页面与关键交互的体验审查，不是 WCAG 全量合规认证。截图不能证明所有读屏器、iOS 真机键盘与缩放行为；16px 与 44px 只说明实现与 Chromium 测量结果。未穷尽每种头像、徽章、长列表组合、全部游戏终局/规则分支，未逐个安装外部 ZIP 或接入真实付费模型；开发开关关闭的实验页面不属于生产界面。官方 AI 空目录与更新未启用状态按本地真实配置检查，不伪造已发布模型或在线更新成功。
