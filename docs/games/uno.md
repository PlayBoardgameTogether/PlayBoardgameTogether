# UNO 与毫不留情

平台以独立在线规则扩展提供 UNO。休闲版 `online.uno@1.2.0` 支持 2–4 人；毫不留情 `online.uno-no-mercy@1.0.0` 支持 2–6 人。管理员分别安装后，玩家直接在大厅或创建房间时选择；单局锁定扩展与精确版本，不在进行中切换。打包、开发下一个扩展及版本规则见 [UNO 包说明](../../game-packages/uno/README.md)。

## 毫不留情

规则依据 [Mattel HWV18 官方说明](https://service.mattel.com/instruction_sheets/HVW18-Eng.pdf)，并对照 [Ubisoft 官方数字版介绍](https://news.ubisoft.com/en-us/article/2OAGx7OmY962DwfAaFf0NI/uno-show-em-no-mercy-dlc-out-now)。使用原创几何牌面，不分发官方美术。它与休闲版的区别包括独立牌组、叠加机制、手牌转移和淘汰，不是只给休闲版增加 +6/+10。

牌组共 168 张，四种颜色各 36 张，万能牌共 24 张：

| 每种颜色 | 数量 |
| --- | --- |
| 数字 0–9 | 每种数字 2 张，共 20 张 |
| 跳过、反转、+2、同色全弃 | 各 3 张，共 12 张 |
| 彩色 +4、跳过所有人 | 各 2 张，共 4 张 |

| 万能牌 | 数量 |
| --- | --- |
| 反转 +4、颜色轮盘 | 各 8 张 |
| +6、+10 | 各 4 张 |

开局每人 7 张，座位 1 先手，顺时针行动；翻出的功能牌忽略留在弃牌堆，直到翻出数字牌。只可出同色、同数字、同符号或万能牌；没有可出牌时一次连续摸到合法牌，随后必须出刚摸到的一张。不能有合法牌仍主动摸牌，也不能保留新摸到的合法牌。

罚牌由下家选择接或承受。可跨颜色接同等或更大的罚牌，比较上一张面值，所有数量累计；承受后跳过。彩色 +4 不选色；万能反转 +4 改变方向，在只剩两位玩家时先回到自己，可用后续罚牌转走。普通双人反转等同跳过；跳过所有人让出牌者再行动。

7 出牌后持久进入选目标阶段，只能选仍在局的其他玩家，确认后双方交换全部手牌；0 使仍在局的所有玩家按当前方向传递全部手牌。同色全弃将其余同色手牌置于该功能牌下方，功能牌保留在顶。

颜色轮盘由下家选色，逐张公开翻出并摸到该颜色为止，万能牌不满足颜色；之后跳过。该阶段刷新后仍等待同一玩家选色；翻牌结果作为公开事件投影，普通摸牌身份仍隐藏。

手牌一旦达到 25 张立即淘汰，停止补牌，将这 25 张放入移出区；下次摸牌堆耗尽时才和可重洗弃牌一起回收，保留顶牌。轮转、换手、跳过和反转只考虑仍在局的玩家。淘汰参与者可继续看公开桌面及回放，但无任何行动，手牌身份不会因此公开。

## 数字版裁定与边界

- 一局出完即胜，或成为唯一未淘汰玩家获胜。不采用可选的累计 1000 分赛制。
- 最后一张立即结束，包括 0、7、罚牌与同色全弃，不再换手、轮盘或追罚。官方简要说明没有详列所有终局组合，本实现以“出完立即结束”作明确裁定，与休闲版末张罚牌处理不同。
- 出牌后剩一张可随出牌声明 UNO。未声明时本人可补喊，其他仍在局玩家可抓漏喊罚摸 2 张；服务端按动作事务先后判定，下一位玩家开始普通行动即关闭窗口，无本地计时器。交换/轮转收到的一张牌不另设抓漏喊窗口。
- 达到 25 张即中止当前补牌；普通连摸或轮盘不会为了完成剩余张数让已淘汰玩家继续摸牌。
- 全员无法再补牌造成停滞，或达到 2000 回合时，仍在局玩家按最少手牌结算，允许并列；不让淘汰玩家因零手牌成为僵局胜者。
- 脚本 AI 只对当前行动席位调度，能叠加、换手、选色和处理自己的 UNO 窗口；不会在其他玩家回合主动抢抓漏喊。真人可在有效窗口内抢抓，仍由服务端验证身份与 revision。
- 未实现 Flip、Flex、Attack、额外的毫不留情 24 张扩充卡/硬币、官方美术、音效、教程或公开战绩摘要。本轮“支持扩展”指可登记、独立安装和版本锁定的规则扩展，不表示所有扩展已经实现，也不提供任意混搭。

## 技术与恢复

`game-packages/uno/editions.json` 登记扩展来源，`scripts/uno-package.mjs` 统一读取源码、生成展示图并打包。每个扩展声明自己的普通 GameExtension；平台使用现有 catalog 安装、QuickJS 限制、本人 View、投影事件、rooms/matches 事务、回执和 AI 控制链路。没有新增平台具体游戏分支、公开协议或数据库迁移。

毫不留情的完整 State 保存手牌/牌堆/移出区、在局席位、方向、罚牌债务、摸到的待出牌、换手/轮盘阶段和 UNO 窗口。序列化校验 168 张唯一牌的身份与守恒、阶段及胜者；每个中间阶段可恢复。非法动作在使用 RNG 前拒绝；合法转换克隆输入，不改写调用者 State。

桌面只消费本人 View 和公开候选。整理牌序属于本地表现；局面或身份变化清理旧选色草稿，相同局面同步保留草稿与键盘焦点。选色使用桌面内联面板，避免长 iframe 的顶层弹窗落在父页面可见区域之外。桌面与手机共用规则，手机玩家区改为两列，长手牌在自己的条带内滚动。结算保留最终本人桌面，再由玩家返回房间。
