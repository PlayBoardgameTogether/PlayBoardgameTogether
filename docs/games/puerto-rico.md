# 波多黎各 · 经典基础版

在线扩展 `online.puerto-rico@1.0.0`，3–5 人。玩家轮流选择角色，经营岛屿与城市，用生产、贸易和装船取得繁荣。七类角色与 23 种基础建筑全部纳入；不含双人、1897 版和扩展。

## 安装与开始

在根目录运行 `node scripts/package-puerto-rico.mjs`，管理员上传生成的 `dist/game-packages/puerto-rico-1.0.0.zip`，完成检查与审核后上架。大厅进入「波多黎各」，创建 3–5 人房间，邀请真人或加入脚本电脑，准备后开局。模型电脑复用平台现有配置与授权，本包没有独立模型请求或凭据。

初始总督随机决定；按总督起顺时针发种植园：3 人靛蓝/靛蓝/玉米；4 人靛蓝/靛蓝/玉米/玉米；5 人靛蓝/靛蓝/靛蓝/玉米/玉米。每人初始金币为人数减一，无初始工人。3/4/5 人的胜利点供给为 75/100/122，工人供给为 55/75/95，工人船另有 3/4/5 人。船舱分别 4–6/5–7/6–8 格。

## 一轮的节奏

从总督起，每人依次选一个本轮未用角色，拿走角色上的累积金币。选择者首先行动并享特权，其余人顺时针行动。淘金者只有选择者行动。所有人选过一次角色后，未选角色各增加一金币，总督顺时针传递。

| 角色 | 全桌行动 | 选择者特权 |
| --- | --- | --- |
| 开拓者 | 拿一块明牌种植园 | 可改拿采石场 |
| 市长 | 分配工人船工人，重新安排全部岗位 | 先从供给额外取一人 |
| 建筑师 | 每人购买一座建筑 | 费用少一金币 |
| 工匠 | 按启用生产链领取货物 | 所有人生产后多取一桶本阶段已生产的种类 |
| 商人 | 向贸易所出售一桶 | 收入多一金币 |
| 船长 | 轮流尽量装船，每桶一分 | 首次装船另加一分 |
| 淘金者 | 其他人不行动 | 取得一金币 |

角色行动通常可放弃，特权也可取消；能够公共装船时必须装船。私有码头可以不用。没有合法生产或贸易时仍可选择放弃以继续阶段。

## 经营与建筑

岛屿和城市各有 12 格，大型建筑占两格，同名建筑不能重复购买。土地与建筑可自由整理，数字版不要求指定格子。采石场和种植园各一个岗位；工厂有 1–3 个岗位。功能建筑和终局加分建筑需要有人工作才生效，建筑基础分始终计入。

市长阶段按顺时针逐人确认全部工人分配；必须尽可能填满岗位，多余工人才待业。阶段末按全体城市空岗位数补工人船，最低人数个。种植园空岗位不算补船需求。

玉米只需启用种植园。靛蓝、蔗糖、烟草、咖啡必须同时有启用种植园与对应加工厂，产量取两者工人数较小值，再受供给限制。工厂收益按实际生产种类计算。大学和招待所先从供给取得新工人，供给空时可从工人船取；大学不能给自身刚建成时发工人，招待所不给庄园额外盲抽地块发工人。

建造费用按启用采石场数减少，上限是建筑所在列的 1/2/3/4（与基础分相同），再叠加建筑师优惠，最低零。采用经典工厂 7、大学 8 金币，未使用交换价格变体。完整建筑效果在棋桌「建筑图鉴」和包内公开说明中可查。

贸易所最多四桶，不能出售已有种类；办公室可例外。小市场和大市场收入可以叠加。满额贸易所到整个商人阶段结束才清空，不满保留到下一次。

## 装船与保存

一条公共船只装一种货物，同种不能占两条公共船。每次选择一种货物，在所选船尽量多装；多条空船可选时，必须选能装最多数量的船，能全部装下的船之间任选。满船本阶段不卸货重用。

港口每次装船加一分，包括私有码头。私有码头每船长阶段可用一次，独立运走一种货物的全部库存，不受公共船容量或种类限制。

无人能继续后，玩家选择剩余货物保留量；默认仅一桶散货。启用小仓库额外保护一种、大仓库保护两种，两者可叠加。其余货物归还供给，然后清空满船；未满船保留。仓库不能用于逃避强制装船。

## 终局与得分

城市用满 12 格、胜利点耗尽，或市长补船工人不足时，标记本轮为最后一轮；所有人完成本轮角色后才结束。筹码耗尽仍继续记录应得分。

总分为筹码、全部建筑基础分及已启用大建筑加分。公会大厅按小/大型生产建筑每座 1/2 分；官邸按岛屿 1–9/10/11/12 块加 4/5/6/7；要塞每三工人加一；海关每四筹码分加一；市政厅每座功能建筑加一，包含自身和其他大建筑。总分高者胜，同分比金币加货物桶数，仍相同则并列。棋桌结算展示分项及同分比较值。

## 交互与隐私

点击角色、建筑或货物先预览，再确认提交；庄园盲抽是独立已提交动作，之后才能决定普通地块，不能撤回抽取。工人阶段可采用建议，再自由修改每个岗位；仓储可逐种填写保留桶数，提交前提示是否超额。选择和表单草稿不进入权威存档，刷新或新动作后重置。

电脑端同时显示公共海港和本人岛屿，手机端优先当前行动及本人货物，港口按需展开。点击玩家摘要查看其公开岛屿，自己的行动仍由自己的 View 决定。棋桌支持独立明暗切换、键盘、原生模态框和减少动态效果；包内样式位于隔离 iframe，遵循平台暖木主题，无全局样式改动。

金币、货物和岗位公开；筹码和含筹码的预估总分只向本人展示，终局公开。牌堆顺序不进入 View。装船事件公开货物与数量，不附带筹码余额。基础脚本只用自身视图对应的合法候选，工人分配使用有界建议，策略不保证最优。真人的全部合法工人/仓储组合由服务器独立校验。

身份、动作事务、去重、并发修订、确定性随机、重连恢复与本人历史回放复用平台，旧局锁定精确版本。ZIP 暂无平台图包、音效、交互教程及内置游戏专用的公开个人得分摘要。游戏包测试通过不代表真实模型供应商已验收。
