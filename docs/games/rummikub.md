# 拉密

拉密通过独立 `online.rummikub@1.0.3` 在线 ZIP 接入平台，2–4 人，支持真人和基础脚本 AI。

打包、上架、规则、桌面交互与验证边界见 [拉密上传包](../../game-packages/rummikub/README.md)。用 `node scripts/package-rummikub.mjs` 生成安装文件，再由管理员在游戏管理上传、检查和审核。无需新增数据库迁移，未上传的环境不会自动显示在大厅。

本版采用灰青绒面数字棋桌和象牙牌，支持首次 30 分、百搭、自由重组、余牌计分及手机点选。1.0.3 将已有公共牌的临时重组实时展示给对手并标注尚未确认，撤销、还原同步；新手牌草稿仍私密。公共排列保存并可恢复，不改变回合和规则局面；确认后沿原正式对局事务提交完整合法桌面。无计时、无超时罚摸，单局结束可在房间重新准备开始。移动动画支持减少动态效果，刷新和回放不会补播历史动作。
